## 📖 About

SpeedFan is a long running hardware monitoring tool originally developed by Alfredo Milani Comparetti. It talks to the sensor chips found on most desktop motherboards through SMBus and reads values such as CPU temperature, system temperature, GPU temperature where exposed, fan RPM, and the various voltage rails. Beyond passive monitoring it can also control fan speed on supported boards, either manually or through automatic rules tied to temperature thresholds, which is why it is often used on older or custom builds where the BIOS fan curve is limited. Recent builds keep the classic compact interface while improving sensor detection on newer chipsets and adding clearer logging of temperature history.

If you came looking for a SpeedFan download for Windows 10 or 11, this page lists the current system requirements, install steps and common troubleshooting fixes. The repository itself is a documentation page, the installer is served from the link in the buttons above and below.

**Good for:** PC builders monitoring fan curves · users with older motherboards and limited BIOS fan control · overclockers watching voltage rails · repair technicians checking thermal behavior · home server owners tracking drive temperatures · anyone diagnosing an overheating desktop.

## 🛠️ Troubleshooting

| Problem | Solution |
|---|---|
| Setup file blocked by SmartScreen | Click **More info**, then **Run anyway**. |
| App opens but shows no temperatures | Right click the shortcut and choose **Run as administrator**, sensor access needs elevated rights. |
| Fan controls are greyed out | Your motherboard sensor chip may not expose PWM control, check the supported chips list in the help file. |
| Readings look wrong or frozen | Close other monitoring tools such as vendor utilities, they can lock the SMBus and block reads. |
| Temperatures spike then drop | Normal on laptops and desktops with aggressive fan curves, verify with a second tool before acting. |
| Charts are empty after launch | Give it a minute to collect samples, the graph fills as readings arrive. |
| Uninstall leaves a folder behind | Remove the leftover directory in Program Files manually after uninstalling. |
